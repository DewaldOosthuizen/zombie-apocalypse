## Format

Each ADD follows this structure:

- **Status**: Current state (Accepted, Superseded, Deprecated, etc.)
- **Context**: The situation and forces at play that motivated the decision
- **Decision**: What was decided
- **Alternatives Considered**: Other options that were evaluated
- **Consequences**: Results and trade-offs of the decision
